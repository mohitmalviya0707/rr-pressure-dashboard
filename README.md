# Reliable Under Pressure: results dashboard

**Mohit Malviya** · SupeRR Selector Season 2, Round 1

An interactive static website: overview, clutch map, model lab (re-weight the rating live), player profiles, head-to-head and robustness. It shows my top 10 batters and bowlers under pressure (IPL + official T20I, 2022–26). Each player has pressure-ball stats, a stability score from a 600-setting stress test, and validation figures.

## What's in this repo
| Path | What it is |
|---|---|
| `index.html`, `style.css`, `app.js` | The dashboard (plain HTML/JS, no build step) |
| `data/results.js`, `data/players.csv` | Summary results only: model outputs for every eligible player (no ball-by-ball rows), generated by `analysis/site_export.py` |
| `vendor/d3.min.js` | d3 v7 (ISC licence, see `vendor/D3_LICENSE.txt`) |
| `analysis/` | The full analysis pipeline (Python), audit and report builder. See `analysis/README.md` |

**No competition data is included.** The ball-by-ball data pack belongs to Rajasthan Royals and must not be shared or published. The `analysis/` scripts need that data pack to run (`bash analysis/run_all.sh "<data pack folder>" out`). Never commit it, or any `out/` folder it produces.

## Run locally
Open `index.html` in a browser. Everything is local, so no server is needed.

## Deploy on Vercel
1. Create a new GitHub repository and upload every file in this folder, keeping the folder structure.
2. On vercel.com, choose **Add New → Project**, import the repository and keep the framework preset **Other**. There is no build command, and the output directory is the root.
3. Click **Deploy**. Your link will look like `https://<project>.vercel.app`.

To update numbers later, replace `data/results.js` (and the CSVs) and push.
